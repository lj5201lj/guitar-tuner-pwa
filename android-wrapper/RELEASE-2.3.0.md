# 弦准 2.3.0 · 识别自检与安全调音

## 本次实现

- 增加 6 秒麦克风自检、系统静音/屏蔽、无样本、无输入、声音太轻、音高不稳定与削波失真提示；提供应用权限设置入口。独立自检结束释放麦克风，已有录音中的自检不会误关原会话。
- 低电平信号先以 YIN 周期性复核，不再直接被旧门限挡住；停顿后清空旧平滑历史，换弦要求连续一致的大跳变。
- 针对已经在测试中复现的强二次泛音高八度误判，增加显著更深的倍周期谷值复核；同时验证真正高音不会因此被降八度。
- 大音名改为检测音；目标音、弦号和标准频率独立显示。超过指针范围和大偏差时提醒核对弦号/八度，不再引导盲目拧紧。
- 连续准确至少 650 ms 后给一次调准触感，可在关于中关闭，并遵循系统设置。保留旧读数时灰显且不触发触感。
- 增加首次麦克风用途说明、离线中英隐私政策、关于/版本、音色素材来源与 CC BY 3.0 署名、安全帮助、主动打开的公开反馈与可选复制诊断模板。
- 无新增运行时依赖，无 INTERNET 或 VIBRATE 权限；关闭应用备份并明确数据迁移规则。公开隐私页由 APK 同一份政策源生成，避免内容漂移。
- 保留 1 秒参考音、余音隔离、中英语言、自定义调弦与节拍器。

版本 2.3.0，versionCode 5，Android 6.0+，沿用原签名和包名，可覆盖安装 2.2.0。

## 验收边界

本地验证：23 项单元测试通过，覆盖标准六弦、弱音渐弱、4 种采样率、强泛音、噪声、换弦、自检分类和连续稳定触感逻辑；Android 发布版 `lintRelease`（0 错误）与 `assembleRelease` 成功。128 组中英文资源的键名和格式占位符核验一致。网页 `test:pitch`、`check`、`build` 成功，公开政策页面从同一份原生政策生成。实际界面操作记录见 `qa/` 脚本输出。

Android 8.0 模拟器通过 24 项自检/权限/隐私检查、16 项调音/节拍回归与 17 项语言/保存/大字体检查，共 57 项。包括真实拒绝系统权限并选择“不再询问”后跳转应用设置。项目公开 GitHub Issues 反馈入口已启用，无自动提交。

自动信号测试和模拟器操作不等于真实手机吉他识别验收。真实六弦、不同手机、系统麦克风隐私开关、Android 13+ 与实际触感仍需按 `qa/REAL-DEVICE-CHECKLIST.md` 验收。
