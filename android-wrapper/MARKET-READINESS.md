# 弦准：从可用 APK 到可上架产品

检查基线：原生 Kotlin 2.3.0。本文区分已经实现的软件能力、尚未进行的真机验收与需要维护者补齐的发布信息，不代表应用宝已经审核通过。

## 2.3.0 前三项的落实情况

1. 已实现麦克风自检、权限设置入口、输入异常提示，并修正弱音门限、旧平滑历史和已复现的泛音八度误判。**尚无真实手机实测结论**；按 `qa/REAL-DEVICE-CHECKLIST.md` 验收，不以模拟器替代。
2. 已区分检测音和目标音，增加超量程与弦号/八度核对提示；旧读数灰显，连续稳定准确后才触发可关闭的系统触感。
3. 已加入录音用途说明、离线中英隐私政策、版本/关于、音色 CC BY 3.0 署名与主动反馈入口。公开政策由同一份源生成。维护者不方便提供姓名/企业与邮箱，**正式商店主体及有效联系方式仍待补齐**，不虚构资料。

入口：顶部“⋮”菜单。APK 无 INTERNET/VIBRATE 权限，不保存或上传录音；本机设置关闭备份并配置迁移排除规则。复制诊断只含应用版本、系统版本与空白问题模板，不自动发出。

已完成 23 项单元测试、57 项 Android 8.0 模拟器操作检查、中英文资源核验、Android 发布构建和签名校验，以及网页测试/类型检查/构建。公开 GitHub Issues 入口已实际启用；公开政策从原生政策源生成。上述结果不能代替真机验收。

## 本次完成的语言能力

- 顶部“文/A”可选择“跟随系统 / 简体中文 / English”，本机保存选择。
- 调音、节拍器、权限提示、自定义调弦、参考音提示与无障碍名称统一使用 Android 字符串资源。其他系统语言默认回退英语。
- Android 13 及以上使用系统应用语言接口；Android 6–12 使用本地配置覆盖。系统设置和应用设置在 Android 13+ 共享同一语言选择。
- 切换时停止录音和播放，保留当前工具、调弦选择与节拍器设置，不自动重开麦克风。
- 两份翻译随包离线提供，未来 AAB 也关闭语言拆包，避免换语言需要临时联网。

## 随后的体验增强

1. 调准反馈：2.3.0 已有连续稳定 650 ms 的一次触感及关闭选项；后续需真机检验不同设备触感是否合适，不把刚扫过零点或旧读数当成完成。
2. 易理解的设置：参考音音量、检测灵敏度和读数保持时长；先提供可靠默认值，再允许高级调整。A4 校准（如 430–450 Hz）可供确有需要的用户使用，默认仍为 440 Hz。
3. 多个自定义调弦：当前只有一个本机自定义方案，可增加命名、复制、删除与离线导入/导出；无需账号或云端。
4. 节拍练习：在现有拍号、点按测速和音色基础上，增加细分拍、重音开关、预备拍、渐进提速和练习计时。先做一种最常用细分，不一次铺满高级功能。
5. 音频设备提示：显示当前输入/输出设备；说明蓝牙播放的延迟，不将“采样帧计时准确”等同于任意设备的可感知零延迟。

## 暂不优先

登录、云同步、社区、广告和订阅不会解决核心的识别问题，还会增加维护和隐私工作。第一款市场版建议保持离线、小体积，把“开得快、听得准、提示清楚”作为主要卖点。

本次已实现前三项的软件能力。真实手机拨弦、系统适配、实际触感与维护者主体资料不能由自动测试补足；完成前不应称为正式商店验收通过版本。后续体验增强仍是建议，未在本次一并实现。
