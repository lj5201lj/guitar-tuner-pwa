# 弦准 2.2.0 · 中文 / English

- 新增顶部“文/A”语言选项：跟随系统、简体中文、English，保存本机选择。
- 完整翻译调音、节拍器、调弦方案、自定义面板、参考音、录音权限及错误提示。
- Android 13+ 接入系统应用语言接口，旧安卓使用原生配置上下文兼容处理，无新增运行时依赖。
- 切换时停止录音与播放，保留当前工具、调弦和节拍器设置，不自动打开麦克风。
- 完整语言资源随包提供，切换不需要联网。
- 改善深色自定义调弦面板的文字对比度，新增语言选择控件的无障碍标签。
- 保留 1 秒参考音自动停止、余音隔离、YIN、标准/特殊调弦和节拍器。

版本号 2.2.0，versionCode 4。沿用原包名和签名，可以覆盖安装 2.1.0。APK 适用于 Android 6.0 及以上，只申请麦克风权限，无登录、网络或数据库。

验证：14 项单元测试通过，91 个默认字符串资源与对应中文翻译完成键名/占位符核验；Android 8.0 模拟器通过 17 项语言/界面操作和 16 项调音/节拍回归检查。`lintRelease` 和 `assembleRelease` 成功。Android 13+ 系统语言接口已实现，但本次没有在该系统版本真机上验收；真实手机拨弦效果仍需实测。

关于正式市场版本的后续建议见 `MARKET-READINESS.md`，其中隐私与关于页面、主体资质和真实手机拨弦验收仍是待办；此版本不代表应用商店已审核通过。
