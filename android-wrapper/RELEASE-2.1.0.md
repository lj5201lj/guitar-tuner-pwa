# 弦准 2.1.0：调音器 + 节拍器

- 在原生 Kotlin App 中集成已有独立节拍器的音频计时引擎，顶部切换两个工具。
- 参考音改为 1 秒自动停止，最后 60 ms 渐弱；点另一根弦会替换当前参考音，无需手动停止。
- 参考音播放及短暂余音期间暂停分析，麦克风保持连接。恢复时清空旧 PCM 窗口、滤波状态及音高历史，并拒绝排队的旧读数。
- 调音录音与节拍播放互斥，切换页面和进入后台都会停止当前工具。
- 节拍器支持 30–300 BPM、±1/±5、点按测速、2/4、3/4、4/4、6/8（3+3）、三种音色及音量，保存本机设置。
- 在竖屏底部常驻调音按钮和六弦选择，避免小屏滚动后找不到控制。
- 保留原包名、发布签名和自定义调弦设置。2.0.0 可直接覆盖安装。

## 验证

12 项单元测试通过，覆盖 YIN 标准六弦检测、弱音拒绝、自定义范围、参考音屏蔽/恢复/旧读数作废、拍号与重音、播放中改速、点按测速，以及 10,000 拍非整数采样间隔累计误差。

`lintRelease` 与 `assembleRelease` 成功。Android 8.0 模拟器已验证旧版覆盖安装、权限与录音启动、参考音自动结束、录音连接保持、快速换弦、节拍输出、播放中改速、切页/后台停止、重启设置恢复；未连接实体手机进行真实拨弦或房间回声测试。

## 安装与使用

在安卓手机中下载并打开 APK，允许该下载来源安装应用，覆盖安装现有“弦准”。选择“调音器”后点“开始调音”，允许麦克风权限；点弦试听，参考音结束且提示恢复识别后单独拨弦。选择“节拍器”后调整 BPM 并点“开始节拍”。

两者使用同一个 App，但不同时输出节拍和识别琴弦，避免节拍器声音混入调音结果。参考音隔离采用短暂暂停/清空，不是连续录音的声学回声消除。独立节拍器应用的历史设置不会跨包自动导入。

APK 仅用于 Android（6.0 及以上），不适用于 iPhone。全部资源离线运行，只请求麦克风权限，无网络、账户或数据库。
